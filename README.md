# Florida Coiffure

Site vitrine de Florida Coiffure, développé en HTML, CSS et JavaScript.

## Structure principale

- `index.html` : accueil
- `coiffure/` : prestations coiffure
- `ongles/` : prestations onglerie
- `produits/` : catalogue et fiches produits
- `diagnostic-capillaire/` : diagnostic et recommandation de routine
- `realisations/` : galerie
- `lookbook/` : inspirations et looks associés
- `assets/css/main.css` : styles du site
- `assets/js/` : interactions et données locales
